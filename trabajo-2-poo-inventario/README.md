# Trabajo 2 · Programación Orientada a Objetos

Sistema de inventario por consola desarrollado con las clases `Producto` e `Inventario`.

## Qué se ha realizado

- `Producto` valida nombre, precio y cantidad desde su creación y al actualizar datos.
- `Inventario` agrega productos, busca por nombre sin distinguir mayúsculas y calcula su valor total.
- Menú interactivo para añadir, buscar, listar y consultar el valor del inventario.
- Manejo de errores de conversión y de valores inválidos mediante excepciones.
- Salida formateada mediante `__str__` para mostrar cada producto de forma legible.

## Ejecución

Desde la raíz del repositorio:

```bash
uv run python trabajo-2-poo-inventario/sistema_inventario.py
```
