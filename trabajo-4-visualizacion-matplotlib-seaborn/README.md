# Trabajo 4 · Visualización con Matplotlib y Seaborn

Análisis visual de ventas minoristas del dataset Superstore.

## Qué se ha realizado

- Preparación del CSV: validación de columnas, conversión de fechas y eliminación selectiva de nulos.
- Figura de cuatro subplots: histograma, boxplot, scatter de ventas-beneficio y barplot de ventas medias.
- Heatmap de correlaciones con Seaborn.
- Scatter 3D y scatter multivariante 2D con Matplotlib, codificando información adicional mediante color y tamaño.
- Exportación de las cuatro visualizaciones PNG incluidas en esta carpeta.

## Ejecución

El script usa rutas relativas para el CSV y los PNG. Ejecútalo desde la carpeta del trabajo:

```bash
cd trabajo-4-visualizacion-matplotlib-seaborn
uv run python visualizacion_superstore.py
```
