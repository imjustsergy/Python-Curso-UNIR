# Trabajo 3 · Análisis de datos con NumPy y Pandas

Notebook de análisis de una red de tiendas a partir de ventas, inventario y satisfacción.

## Qué se ha realizado

- Carga y limpieza de `sales.csv`, `inventories.csv` y `satisfaction.csv`.
- Uso de NumPy y Pandas para cálculos agregados, métricas y proyecciones.
- Cruce de fuentes para relacionar ventas, existencias y satisfacción de clientes.
- Interpretación de resultados orientada a la toma de decisiones de la red de tiendas.

## Recursos

El notebook y los tres CSV se conservan juntos en esta carpeta. El código mantiene la ruta `/workspace`, que era la ruta del entorno de evaluación de UNIR. Para ejecutarlo localmente con Jupyter, cambia `RUTA_BASE` por la carpeta actual del trabajo antes de ejecutar las celdas.
