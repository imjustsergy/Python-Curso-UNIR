# Trabajo 1 · Sintaxis Python

Programa de consola que calcula promedios escolares aplicando programación estructurada.

## Qué se ha realizado

- Entrada repetida de materia y calificación, con validación numérica entre 0 y 10.
- Almacenamiento paralelo de nombres de materias y calificaciones en listas.
- Cálculo del promedio general.
- Clasificación de materias aprobadas y reprobadas con umbral 5,0.
- Identificación de la mejor y peor calificación, incluyendo el caso sin materias registradas.

## Ejecución

Desde la raíz del repositorio:

```bash
uv run python trabajo-1-sintaxis-python/calculadora_promedios.py
```
